\section{The Seshat-Star pipeline}
\label{sec:pipeline}

The pipeline has four roles and no component holds two.
Geometry computes what is true of the room.
A writer model decides what to say.
A reader model translates the finished sentence back into relations, and a verifier checks whether those relations leave only the target.
This section describes the first two \TODO{(method figure)}; \cref{sec:scorer} describes the others.

\paragraph{Scene and candidates.}
The input is a scan with instance labels: for each object an id, a class name and its points.
For a target set $T$, the \emph{candidates} $C$ are all objects whose class shares the target's head noun, so that \emph{office chair}, \emph{folding chair} and \emph{chair} compete; the \emph{distractors} are $D = C \setminus T$.
A sentence has to separate $T$ from $D$ by spatial cues.
Attributes stay as the annotator wrote them, unverified, and by design carry none of the disambiguation.

\paragraph{Evidence.}
Operators turn the instance table into a block of facts in plain text, indexed by object id, each covering something a rendering shows poorly:
the nearest landmarks of the target and of each distractor, with surface gaps in metres;
places to stand, given as ``at $A$, facing $B$'', with the left-to-right order of the candidates from there;
which candidates form rows, and the target's row and seat counted from a named end;
the face, end or corner of a large piece of furniture at which an object sits;
what rests on what;
and the wall, corner or end of the room an object belongs to.
The block closes with the distractors the sentence must exclude.
The heavier facts, rows and furniture faces, are given only when the target has five or more distractors; in emptier rooms they made the writer over-describe.
No operator was right the first time.
Each revision began with a failure the authors found by reading rewrites next to the point cloud, some 1,500 of them over at least 245 scenes.
Rows are the clearest case: what separates a row a person sees from a row only the algorithm sees turned out to be its isolation from other objects of the class, not its straightness (\supp{supp:operators}).

\paragraph{Writer.}
The writer is GPT-5.5 at high reasoning effort.
It receives renderings of the point cloud from several cameras with the objects marked by id, a top-down outline of the room, the instance table, the fact block and, when there is one, the original sentence.
It returns a sentence and the list of relations that sentence uses, each written over object ids.
The sentence is its own: which of a few dozen facts to use, where to stand, in what order to speak, which of the annotator's words to keep.
It may add what it sees and we did not compute (\emph{hanging on the rod}); such relations stay in the free text and are not scored.
Without an original sentence the same prompt runs minus the paragraphs that mention one.
We run the pipeline over ScanRefer, Multi3DRefer, Nr3D and Sr3D in full, except Multi3DRefer's zero-target entries.

\paragraph{The writer obeys evidence; it does not weigh it.}
Told that our label lookup found nothing in the scene for a word of the original sentence, the writer kept that word in 22 of 114 cases; told nothing, in 108; told the same with a disclaimer attached, again in 108.
Three instructions to keep such words were in force throughout.
When the evidence said the target stood in no row, none of 410 rewrites said otherwise (\supp{supp:writer}).
An operator's mistake therefore enters the corpus at full strength, and nothing downstream corrects it.
The same holds for the scorer's verdict on a rewrite: fed back, it would be obeyed like any other assertion, and the scorer would then be measuring sentences written to satisfy it.

\paragraph{What is guaranteed and what is measured.}
Of the four properties in our title, one holds by construction.
The rewrites are \emph{verifiable}: every relation the writer takes from the fact block is stored with the sentence as a predicate over object ids, and anyone with the scene can evaluate it again.
The relations the writer names freely are outside this guarantee.
\emph{Unambiguous} and \emph{rich} are measured, sentence by sentence, by the scorer and by people (\cref{sec:scorer,sec:data}); they cannot be guaranteed, since no verdict returns to the writer.
That the sentences read as \emph{natural language} is a design intent, served by free text and by keeping the annotator's words.
We do not measure it.
